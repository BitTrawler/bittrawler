BitTrawler is a self-hosted BitTorrent indexer: it crawls the DHT, classifies what it finds, keeps the result in local SQLite files and serves it to Prowlarr, Sonarr and Radarr over Torznab. It is a Go fork of [bitmagnet](https://github.com/bitmagnet-io/bitmagnet) which is designed to solve all of the problems associated with bitmagnet: high disk usage, weak searching and poor categorisation.

As of v1 BitTrawler is effectively feature-complete. You can install it, start it up and connect it to prowlarr and it will just work. Sonarr and other apps will be able to accurately search against it and use it.

**Features as of v1:**
- Trawl the DHT network and gather up torrents
- Manually search against gathered torrents
- UI login system and API key for other apps
- Full torznab/prowlarr support (including accurate search results and series search results for sonarr)
- Partitioned DB (drop old data over time to prevent infinite growth)
- Automatically block illegal torrents such as CSA
- Automatically block deceptive torrents such as malware disguised as video files
- Automatically drop XXX torrents (optional)
- Automatically drop foreign torrents (optional, by script)
- Automatically categorise torrents by looking at file features, titles, known XXX performer names etc
- Configure everything within the app, no text files required!
- Start/stop trawling within the app.

Enjoy!
